# fractional_ownership_of_rwas

## Topic

Fractional ownership of RWAs. Design a contract for fractional ownership of a high-value asset. Research the novel problems like governance among fractional owners, exit/liquidity, dispute resolution and prototype a solution to one.

## Repository layout

| Folder       | What goes there                                                        |
|--------------|------------------------------------------------------------------------|
| `src/`       | Solidity contracts                                                     |
| `test/`      | Hardhat tests for the contracts                                        |
| `scripts/`   | Scripts that produce every number and figure in the paper              |
| `data/`      | Measurement outputs (CSV) written by the scripts                       |
| `figures/`   | Figures generated by scripts — never edited by hand                    |
| `notebooks/` | Exploratory analysis                                                   |

## Requirements

- Node.js 22 (LTS) and npm 10
- Python 3.11+ (only for plotting)

Exact JavaScript dependency versions are pinned in `package.json` and `package-lock.json`.
The Solidity compiler is pinned to **solc 0.8.28** (optimizer on, 200 runs, EVM `cancun`) in `hardhat.config.js`.

## Install

```bash
git clone https://github.com/aminasadybek/fractional_ownership_of_rwas.git
cd fractional_ownership_of_rwas
npm ci
```

## Run

```bash
npx hardhat compile
npx hardhat test
```

## Reproduce the measurements

```bash
# 1. Gas measurements on the local Hardhat network -> data/*.csv, data/gas_run_metadata.json
npx hardhat run scripts/measure_gas.js

# 2. Figure -> figures/exit_cost_vs_owners.png
python -m venv .venv
.venv\Scripts\activate          # Windows  (macOS/Linux: source .venv/bin/activate)
pip install -r requirements.txt
python scripts/plot_exit_cost.py
```

The measurement is deterministic: accounts come from Hardhat's fixed development mnemonic and no random numbers are used, so gas figures are identical on every machine with the pinned versions. `data/gas_run_metadata.json` records the compiler, library versions and date of the run.

| Output                          | What it contains                                                            |
|---------------------------------|-----------------------------------------------------------------------------|
| `data/gas_operations.csv`       | Gas per single operation (deploy, fractionalize, transfer, redeem)          |
| `data/exit_cost_vs_owners.csv`  | Gas for one buyer to re-collect all shares from N owners, then redeem       |
| `figures/exit_cost_vs_owners.png` | Plot of the above                                                         |
